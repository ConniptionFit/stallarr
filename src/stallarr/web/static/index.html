Import from Prowlarr

Adds every torrent tracker in Prowlarr and pulls its API key.

Automatic sync adds new trackers as they appear in Prowlarr and replaces API keys that were rotated there. Sites that are neither a known plugin nor stock UNIT3D come in on the generic driver: their torrents are monitored from qBittorrent, but stallarr cannot ask the site about them.

Prowlarr masks cookies and never stores announce passkeys, so cookie-authenticated sites (IPTorrents) and the refresh announce step still need those entered below by hand.
